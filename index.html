BUILT FOR ROBOTICS WORKFLOWS

Every utility, library, and configuration pre-packaged in RoboOS addresses real robotics development bottlenecks.

Terminal-First Philosophy

Starts in TTY mode with optional XFCE 4.18 desktop (`startx`). Zero heavy display managers wasting RAM and CPU cycles required for real-time control loops.

Native Protocol Stack

Built-in system modules for instant hardware discovery: CAN bus (SocketCAN), Serial microcontrollers, USB devices, V4L2 cameras, and PipeWire audio.

Pre-configured Workspace

Default ~/robot_ws populated with standard ROS/ROS2 directory structures (src, build, install, log) and Thunar context actions.

Unified `robo` CLI

Control your OS using one coherent interface. Diagnose dependencies with robo doctor or audit hardware peripherals with robo devices.

AI & Vision Ready

Core developer toolchain includes C/C++, Python 3, CMake, Git, GDB, OpenCV bindings, and PyTorch / CUDA hardware acceleration hooks.

GTK4 Control Center

Custom settings dashboard built specifically for power profile switches, display configuration, NetworkManager Wi-Fi, and BlueZ Bluetooth.
